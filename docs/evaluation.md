# Evaluation Plan

- Precision@5
- Recall@5

## Generation Metrics

- Faithfulness
- Answer relevance
- Context precision

- Task completion rate
- Error rate

Phase 3 should use at least 20 research questions spanning several domains. Each benchmark should include relevant papers, evidence summaries, and citation ground truth.
